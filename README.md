# Dirt Rally

A browser-based 3D dirt rally racing demo built with [Three.js](https://threejs.org/) and Vite.

Drive a rally car around a closed dirt stage with hills, berms, trees, and dust. Arcade handling with loose grip, handbrake slides, lap timing, and a chase camera.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3847](http://localhost:3847).

## Controls

| Key | Action |
| --- | --- |
| `W` / `↑` | Accelerate |
| `S` / `↓` | Brake / reverse |
| `A` `D` / arrows | Steer |
| `Space` | Handbrake |
| `R` | Reset stage |

## Stack

- TypeScript
- Vite
- Three.js (WebGL)

## Build

```bash
npm run build
npm run preview
```
